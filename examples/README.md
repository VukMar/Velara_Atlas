# Noncanonical JSON examples

Start with [the v1.2 entity-family guide](v1_2/README.md). It explains the ten
focused examples, required/nullable fields, variations and authoring stages.

The complete working implementation is [public/datasets/demo](../public/datasets/demo/sector.json).
Examples are independent developer references, excluded from runtime and builds;
they do not register IDs or establish canon. These remain v1.2 references; the active Demo is v1.3. Use the
[v1.2 reference schema](../schemas/atlas.schema.json), the
[active v1.3 contract and migration guide](../docs/DATA_MODEL_V1_3_PROPOSAL.md),
[data model](../docs/DATA_MODEL.md) and [navigation authoring guide](../docs/NAVIGATION_AUTHORING.md)
for the full contracts. Historical JSON proposals remain in
[the archive](../docs/archive/json-proposals/README.md); legacy regression inputs
remain in [tests](../tests/fixtures/legacy_examples/README.md).
