    NEXUS / CHART GUIDANCE

    Map controls

    Drag with the primary pointer button to pan. Use the mouse wheel or trackpad scroll to zoom. In 3D, right-drag to orbit.

    On touchscreens, drag one finger to pan. Pinch with two fingers to zoom; in 3D, move two fingers to orbit.

    Select a marker, mapped record or Catalogue result to read its InfoCard. Double-click a system on the map, or use Enter System in its InfoCard, to enter it. Double-click another mapped object or use Focus Selection to inspect it.

    Focus the chart and use arrow keys to pan, + or − to zoom. Map Controls provides zoom buttons, 2D/3D switching and camera elevation in 3D.

    Reset View returns to the chart framing. Focus Selection inspects the selected object where available. Escape closes the active InfoCard, dialog or toolbar.
